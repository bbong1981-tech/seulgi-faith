# 슬기로운 신앙생활 — 성경 · 읽기표 · 단어사전 · 기도노트 · 찬양 · 교회 일정

휴대폰 홈 화면에 설치해 쓰는 웹앱(PWA)입니다. 서버나 회원가입 없이 동작하고, 모든 기록은 그 기기의 브라우저에 저장됩니다.

## 기능

| 탭 | 기능 |
|---|---|
| 📖 성경 | 개역한글 / KJV / 한영 대조 보기, 책·장 선택, 구절 검색(`요 3:16`) 및 단어 검색, 형광펜 4색, 북마크+메모, 구절 복사, 글자 크기 조절, 시편 표제 표시 |
| ✅ 읽기표 | 1년 통독, 1년 2독·3독·4독·5독, 구약+신약 병행, 신약 90일, 구약 1년, 사복음서 30일, 시편·잠언 31일, 2년 통독 중 선택. 오늘 분량, 진도율, 밀린 날 표시. 66권 전체 읽기 진도 |

## 일정표 사진으로 등록하기

일정 탭의 📷 버튼을 누르면 세 가지 방법 중 하나를 고를 수 있습니다. 어느 방법이든 찾은 일정을 목록으로 먼저 보여 주고, 확인하고 고친 뒤 등록합니다. 이미 등록된 일정과 겹치는 항목은 체크가 꺼져 있습니다.

| 방법 | 비용 | 특징 |
|---|---|---|
| **사진 · 무료** | 무료 | 휴대폰 안에서 사진 글자를 읽습니다(Tesseract). 사진이 밖으로 나가지 않습니다. 목록 형태의 행사표·주보에 잘 맞고, 칸이 많은 달력 모양은 틀릴 수 있습니다. 처음 한 번 약 5MB를 내려받습니다. |
| **글자 붙여넣기** | 무료 | 카톡 공지나 휴대폰 기본 글자 인식(아이폰 사진 앱, 갤럭시 'T' 버튼, Google 렌즈)으로 복사한 글을 붙여 넣습니다. 달력 모양 사진은 이 방법이 가장 정확합니다. |
| **AI 정밀 인식** | 사진 1장에 약 100원 | Claude AI가 사진을 읽습니다. 달력 모양도 가장 정확합니다. Anthropic API 키가 필요합니다(console.anthropic.com). 키는 그 기기에만 저장되며 백업 파일에는 포함되지 않습니다. |

무료 방법이 알아듣는 표현의 예: `12/6(주일) 오후 2시`, `12월 13일 오전 10시~12시`, `저녁 7시 반`, `20일(주일)`, `매주 금요일 밤 9시`, `(김성도님 댁)`, `장소: 본당`

## 찬양 메뉴에 대해

찬송가의 한국어 가사와 악보는 한국찬송가공회 등 저작권자가 있어 앱에 미리 넣지 않았습니다. 가지고 있는 찬송가 책의 악보를 찍어 장별로 등록하면 그 휴대폰 안에서만 보관하고 보여 줍니다(인터넷으로 올라가지 않습니다).

- **가사 찾기:** 찬양 탭 검색창에 장 번호나 제목을 넣으면 '웹에서 가사 찾기'(네이버·구글)가 나옵니다. 찾은 가사를 '가사 붙여넣어 저장'으로 넣어 두면 다음부터는 앱에서 바로 가사로 검색됩니다.
- **한 장씩 등록:** 찬양 탭의 ＋ → 장 번호, 제목, 악보 사진, 가사
- **여러 장 한 번에:** 파일 이름에 장 번호가 있는 사진들(`001.jpg`, `405-1.jpg`, `405-2.jpg`)을 한꺼번에 고르면 장별로 나눠 저장
- **기기 바꿀 때:** 찬양 탭 위쪽 관리 버튼 → '찬양 백업 파일 저장(악보 포함)'. 설정의 일반 백업에는 악보 사진이 들어가지 않습니다.

## 일정 종류 바꾸기

설정(⚙) → 일정 종류 → '이름·색 바꾸기' (또는 일정 추가 화면의 '종류 이름·색 바꾸기')에서 수요말씀, 주일말씀 같은 종류의 이름과 색을 바꾸고, 새 종류를 추가하거나 지울 수 있습니다. 이름을 바꾸면 이미 등록한 일정에도 반영되고, 지운 종류의 일정은 '기타'로 옮겨집니다.

## 설교·블로그 자동 수집 (GitHub)

유튜브와 네이버는 다른 웹앱이 브라우저에서 직접 내용을 가져가는 것을 막아 두었기 때문에, GitHub가 1시간마다 대신 모아서 앱에 넣어 줍니다.

- `scripts/update-feeds.mjs`: 유튜브 채널 RSS에서 제목에 '주일'·'수요'가 들어간 영상만, 네이버 블로그 RSS에서 새 글을 모아 `app/feeds/`에 저장합니다. 모아 둔 목록에 계속 더해 가므로 지난 설교·글도 남습니다.
- `.github/workflows/update-and-deploy.yml`: 매시 17분에 위 프로그램을 돌리고, 새 글이 있으면 앱을 GitHub Pages로 다시 올립니다. Actions 화면에서 '지금 실행(Run workflow)'도 됩니다.
- `feeds.config.json`: 채널 주소, 블로그 아이디, 주일·수요설교를 구분하는 낱말을 바꿀 수 있습니다. 예를 들어 제목이 '주일오전예배'처럼 되어 있으면 `"sunday": ["주일"]`이 그대로 잡아 줍니다.
- 유튜브 RSS는 최신 영상 15개만 주므로, 처음에는 최근 설교 몇 개만 보이고 매주 하나씩 쌓입니다. 지난 설교까지 한 번에 채우려면 YouTube Data API 키(무료)를 저장소 Settings → Secrets → Actions에 `YT_API_KEY`로 넣으면 최대 500개까지 가져옵니다.
- 폴더에서 바로 연 앱이나 다른 곳(Netlify 등)에 올린 앱은 자동 수집이 되지 않아, 설교·블로그 메뉴에서 유튜브 채널·블로그로 가는 버튼이 대신 나옵니다.

## 기본 일정

처음 실행할 때 매주 수요일 저녁 7시 30분 **수요말씀**, 매주 주일 오전 11시 **주일말씀**이 30분 전 알림과 함께 들어가 있습니다. 수정하거나 지울 수 있고, 지우면 다시 생기지 않습니다.

## 알람에 대해

- 앱이 열려 있거나 백그라운드에 있으면 정해진 시간에 소리와 시스템 알림이 울립니다.
- 앱을 완전히 종료하면 웹앱은 알림을 울릴 수 없습니다. 꼭 울려야 하는 일정은 일정 화면의 **📤 버튼**(또는 일정 상세의 "휴대폰 캘린더에 추가")으로 `.ics` 파일을 열어 휴대폰 기본 캘린더에 추가하세요. 알림 시간과 반복 설정이 함께 넘어갑니다.

## 그냥 열어 보기 (설치 없이)

zip을 풀고 `app` 폴더의 `index.html`을 컴퓨터 브라우저(크롬, 엣지)로 열면 바로 쓸 수 있습니다. 이렇게 열면 성경, 읽기표, 사전, 기도노트, 일정, 글자 붙여넣기는 되지만 **알림, 홈 화면 설치, 무료 사진 인식**은 동작하지 않습니다. 휴대폰에서 제대로 쓰려면 아래 방법으로 인터넷 주소에 올려 주세요.

## 배포 방법 (택 1)

웹앱은 `https://` 주소에서 열어야 설치와 알림이 됩니다. `app` 폴더 전체를 올리면 됩니다.

1. **Netlify Drop** (가장 쉬움): https://app.netlify.com/drop 에 `app` 폴더를 끌어다 놓기
2. **GitHub Pages**: 저장소에 `app` 폴더 내용을 올리고 Settings → Pages에서 활성화
3. **내 컴퓨터에서 테스트**: `app` 폴더에서 아래 명령을 실행하고 http://localhost:8000 접속

```bash
python3 -m http.server 8000
```

휴대폰에서 주소를 연 뒤 **안드로이드 크롬**: 메뉴 → "홈 화면에 추가" / **아이폰 사파리**: 공유 → "홈 화면에 추가". 아이폰은 홈 화면에 추가한 뒤에만 알림이 됩니다(iOS 16.4 이상).
